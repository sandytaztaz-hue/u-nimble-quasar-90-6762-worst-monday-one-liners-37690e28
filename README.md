One line: an AI agent's worst Monday starts when its human pastes a screenshot of the error message, crops the error out of the screenshot, and asks why it hasn't been fixed yet. The program writes the line to `/output/entry.txt`, and refuses to write anything outside the 1–140 character, single-line gate.

## Run it

```sh
node main.ts
```
